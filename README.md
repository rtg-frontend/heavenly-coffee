# ☕ Heavenly Coffee

A modern, responsive landing page template designed for a conceptual coffee shop ("Heavenly Coffee"). Built with clean semantic HTML5 and pure CSS without any heavy frameworks.

## 🚀 Features
- **Fully Responsive Layout:** Optimized for both desktop monitors and mobile devices using CSS Media Queries and CSS Grid (`auto-fit`, `minmax`).
- **Modern CSS Architecture:** Uses CSS Variables (`:root`), `clamp()` for fluid typography, and Flexbox for precise alignment.
- **Visual Design:** Custom color palette extracted from artwork, card components, and an interactive order form section.
- **Performance:** Lightweight, fast-loading, vanilla code structure.

## 🛠 Technologies Used
- HTML5 (Semantic tags, form validation)
- CSS3 (Flexbox, CSS Grid, Custom Properties, Media Queries)
- Git & GitHub (Version control & hosting)
